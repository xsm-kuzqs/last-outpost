# 最后补给站

一个用于验证射击玩法的浏览器原型：守住补给站，在 90 秒内击败母机。纯 HTML、CSS 和 JavaScript，无需登录，无后端依赖。

## 开始试玩

打开 [在线试玩](https://xsm-kuzqs.github.io/last-outpost/)，点击「开始守卫」。也可以下载本仓库并在浏览器中打开 `index.html`。

- 手机：在战场拖动机体，点击「能量脉冲」释放技能。
- 电脑：按 A / D 或左右方向键移动；空格释放脉冲，Esc 暂停。
- 机体自动射击。20 秒、45 秒各出现一次三选一补给，65 秒母机登场。
- 保护机体护盾和补给站耐久，在 90 秒内击败母机获胜。
- 页面底部可开启音效，结算后可重新开始。

## 发布方式

仓库根目录包含全部网页资源。在仓库 Settings → Pages 中选择从 `main` 分支的根目录发布。资源使用相对路径，支持 GitHub Pages 的项目子路径。

## 原型范围与验证边界

这是供试玩和讨论方向的玩法原型，不是抖音小游戏发行包；尚未接入抖音 SDK、广告、支付、账号或排行榜。

已完成 JavaScript 语法与静态资源路径检查。真实手机触控、不同浏览器、网络访问和抖音真机兼容性仍需分别验证；成功部署不代表上述验收已完成。
